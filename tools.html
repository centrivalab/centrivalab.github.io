Tools

Free calculators and planners to design an experiment before you spin. All run in your browser; no membrane parameters are needed for the polarisation tools.

Estimate

CP Calculator

Predicts the polarisation factor, wall concentration, mass-transfer coefficient and intrinsic rejection of your solute in a CentrivaLab cartridge, and the rotor speed for a target mean pressure.

Use it when: You know the solute, concentration and flux you expect and want to see how strong polarisation will be.

Open CP Calculator →

Quick tool

Rotor Speed

Converts between rotor speed and mean transmembrane pressure for each cartridge and rotor.

Use it when: You only need the rpm for a target pressure, or the pressure at a given rpm.

Open Rotor Speed →

Plan

Test Planner

Starts from a spiral-wound module test (size, flux, recovery) and returns the rpm and starting concentration that give the same wall concentration in a CentrivaLab cartridge.

Use it when: You want to reproduce a module-scale test at screening scale.

Open Test Planner →

Plan

Batch Planner

Plans a batch (concentration, diafiltration or solvent exchange) as a sheet of six tubes, one per time point, with the C·J curve and room to re-enter measured results.

Use it when: You need time-resolved information from a batch process.

Open Batch Planner →

Compare

Device comparison

Puts the O-CMF side by side with a stirred cell and a spiral-wound module for the same solute, flux and conditions.

Use it when: You want to see how your current device compares with the CentrivaLab cartridge.

Open Device comparison →

Compare

OSN Simulator

The same comparison for organic solvents and macromolecules, with solvent, temperature and solute properties; PEG, globular and small solutes, solvent mixtures with water.

Use it when: You work in organic solvent nanofiltration, or with PEG, peptides or proteins.

Open OSN Simulator →

Where to start: to reproduce a module-scale test, use the Test Planner; for a batch process, the Batch Planner; to estimate polarisation for a known solute, the CP Calculator. The OSN property guide documents the physical properties behind the OSN Simulator.
